Bagaimana Cara Kerja Download & Offline Cache?

Cukup tekan tombol "Unduh Semua Offline" di bagian atas. Seluruh berkas audio akan diunduh dan disimpan ke memori penyimpanan lokal browser (IndexedDB).

Setelah status berubah menjadi ✓ Siap Offline, lagu tersebut tidak perlu didownload ulang dan dapat diputar meskipun laptop/HP Anda tidak terhubung ke internet sama sekali di lapangan upacara!

2

Cara Mengunggah ke GitHub Pages

  1. Buat repository baru di GitHub (misal: upacara-player).
  2. Upload folder audio/, soundfonts/, dan semua file web (index.html, style.css, app.js, audio-engine.js, db.js, songs.json, sw.js, manifest.json).
  3. Buka Settings di GitHub → menu Pages.
  4. Pilih branch main dan folder / (root) → Klik Save.
  5. Website siap diakses di https://username.github.io/upacara-player!
